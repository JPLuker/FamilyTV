# Decisions

FamilyTV is a temporary name. Branding and mascot require Joseph's approval. Parent controls are server enforced. No child approval requests. No autoplay for on-demand. No third-party telemetry. Accessible navigation is a baseline. Compose uses PostgreSQL with a single versioned household record. Mutations lock that record until commit.

After installation, routine parent tasks belong in the web dashboard, including choosing folders within shared media, reviewing videos and naming screens.
